GlycanEvidence

将菌群身份、局部基因结构与读段支持连接成可核查的证据链。

本项目围绕青藏高原母婴纵向研究中的营养与肠道宏基因组数据，提供局部糖利用基因区域分析方法。GlycanEvidence 分别记录标记信号、锚点间结构、边界片段和碱基支持，使参考映射之外的局部结构具有明确的输入、判据和来源。

公开版本 0.1.0.dev10 · 更新于 2026年10月22日 · 研究软件

四层方法证据

01 · MARKERS & LOCI

分别记录身份与基因区域

冻结标记判据，保留覆盖、片段数和可检测性信息，将身份证据与局部基因区域信号分别输出。

标记引擎与判据
02 · LOCAL STRUCTURES

恢复并比较局部结构

结合候选参考结构、片段分配和普通组装区间，记录完整或部分锚点结构、参考差异及尚未解决的候选。

结构恢复接口
03 · READ & SEQUENCE SUPPORT

检查边界与序列支持

核对直接跨界片段、逐碱基支持与编码序列，保留支持不足、比对冲突和部分区间。

碱基与片段核查
04 · COMPARISON & CONTEXT

连接方法比较与群体背景

在相同输入与明确判据下比较扩展参考和普通组装，并提供营养酶序列、可比较群体背景及预指定事件读回的分析组件。

比较与序列分析代码

安装与运行

建议使用 Python 3.12 或更新版本。安装后可先运行合成测试，再按接口准备自己的数据、参考序列和来源清单。

git clone https://github.com/chanucy97/Fan_LAB.git
cd Fan_LAB
python -m venv .venv
source .venv/bin/activate
python -m pip install './projects/milk_gut_scfa_plateau/glycan-evidence[inference]'
glycan-evidence --help
cd projects/milk_gut_scfa_plateau/glycan-evidence
python -m unittest discover -s tests -v

Windows 激活命令为 .venv\Scripts\Activate.ps1。BAM 分析另需 pysam；原始读段流程需 Linux 生物信息工具。不同模块的依赖、输入格式和命令见各自 README。

评价范围

本方法强调结构、序列和来源的可核查性。既有开发比较中，组装辅助规则识别23/35个正确结构类别、无额外类别，与普通组装的几何识别结果相同。组装已恢复的结构不计作优于组装的新增发现；局部序列证据也不单独确定菌株归属或营养利用功能。

代码保留原有科学判据；通用运行适配与原始研究代码的差异记录在各目录的来源文件中。队列专用输入与部分历史执行脚本另按数据访问流程提供。
