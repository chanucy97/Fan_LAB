# 樊海宁课题组官网初版

这是 `Fan_LAB` 仓库中的公开官网草稿目录，和内部项目索引、代码规范、数据规则分开管理。

## 文件

- `index.html`：单页静态官网
- `styles.css`：页面样式

## 当前内容

- 首页定位
- PI 简介
- 研究方向
- 公开成果亮点
- 人才培养统计与重绘名单
- 当前成员：樊海宁、铁成炜、姜超
- 学生照片：王世龙、逯克荣、成文军、范赐鹏、唐金鑫
- 学生二级资料页：`students/*.html`
- 试剂耗材栏目：`reagents.html`
- 动物台账栏目：`animals.html`
- 公开资料来源
- 联系方式占位

## 试剂耗材记录说明

`reagents.html` 当前展示结构化物资明细，并提供 Excel 台账下载；`animals.html` 单独展示实验动物台账，重点维护保种沙鼠、感染源来源链条、负责人矩阵和待补字段。若后续需要多人共享、权限控制或长期备份，应改为 Excel/CSV 数据源或接入后台数据库。
- 经授权可公开的课题组照片或医院/实验室场景图

## 公开边界

官网只放公开展示信息。内部项目路径、患者数据、样本映射表、未发表结果、服务器路径、原始数据和未清理代码不应放入该目录。
