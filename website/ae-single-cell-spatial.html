方法范围 Scope

公开内容限于通用方法说明和辅助函数，不包含研究结果、原始数据、源表或图表输出，也不构成完整原始分析及制图代码的存档。

The public resource is limited to general method descriptions and helper functions. It contains no study results, original data, source tables or figure outputs, and does not constitute an archive of the complete original analysis or figure-generation code.

使用说明 Using the methods

先阅读 README 和方法文档，确认输入格式、软件依赖及函数适用范围。分析设计、参数选择与结果解释需由使用者结合自己的数据确定。

Start with the README and methods documentation to check input formats, dependencies and function scope. Users determine the analysis design, parameters and interpretation appropriate to their own data.

初始方法版本日期为 2026-09-15。使用或引用时，请记录对应的 Git 提交版本；当前无归档 DOI。

The initial methods version is dated 2026-09-15. Record the Git commit when using or citing the resource. No archival DOI is currently assigned.
