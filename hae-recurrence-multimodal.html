Research Code · Survival Modelling

肝泡型包虫病术后复发：多模态生存建模

Multimodal survival modelling for postoperative recurrence in hepatic alveolar echinococcosis

公开的生存建模与评估源码，连接临床、常规影像组学、生境影像组学和 2.5D 深度特征四个信息维度。研究者可使用自己的表格特征与结局数据，按照示例配置开展分析。

Public source code for survival modelling and evaluation using four dimensions of prepared tabular features, with example input configurations for researchers to adapt to their own data.

分析范围 Scope and workflow

本资源从已准备的表格特征进入分析，公开内容包括生存建模、预测评估源码与示例输入配置。原始影像预处理、特征提取以及从原图到论文的完整分析流程不在本次发布范围内。

The release starts from prepared tabular features. It covers survival modelling, prediction evaluation and example input configurations; it does not provide image preprocessing, feature extraction or the complete image-to-publication workflow.

  1. 01 · INPUT

    四维表格特征

    临床、常规影像组学、生境影像组学、2.5D 深度特征。

  2. 02 · TRAIN

    训练内筛选与嵌套交叉验证

    在相应训练分区内处理变量、筛选特征并拟合模型。

  3. 03 · FUSE

    四种融合策略

    特征级、评分级、等权秩均值与门控注意力融合。

  4. 04 · EVALUATE

    生存预测评估

    C-index、36 个月 AUC 与 Brier、分组校准和决策曲线。

核心代码 Source files

五个核心脚本位于项目的 code/ 目录。输入约定、运行环境与配置方式见 项目 README。

  • run_rigorous_analysis.py分析入口：输入检查、嵌套建模与结果导出。
  • analysis_core.py表格特征处理、稀疏 Cox 模型与交叉拟合。
  • clinical_schema.py临床变量定义、类别编码与输入规则。
  • attention_core.py四维评分的门控注意力融合与生存概率映射。
  • evaluate_survival.py生存预测评估、患者级自助抽样与汇总输出。

使用准备 Getting started

  1. 阅读项目 README 与方法说明，确认所需依赖及各输入表的格式。
  2. 参照示例填写特征路径、临床变量定义、队列标识与固定分区，使用自己的研究数据。
  3. 先运行输入检查，再执行分析；保留配置、运行记录与使用的 Git 提交版本。
