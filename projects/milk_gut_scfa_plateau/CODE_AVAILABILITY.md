# Code availability

GlycanEvidence (version 0.1.0.dev10), its synthetic tests, and companion code for structure comparison, sequence integrity and population-background analysis are available in the Fan_LAB repository at https://github.com/chanucy97/Fan_LAB/tree/main/projects/milk_gut_scfa_plateau . The laboratory website provides the method overview at https://chanucy97.github.io/Fan_LAB/glycanevidence.html .

The source snapshot dated 22 October 2026 is identified by the Git tag `glycanevidence-dev10-20261022`. The public implementation preserves the accepted method code and frozen identity rules. Companion `public-adapter.v1` records describe changes needed to accept user-supplied paths and configurations. Requirements, input schemas, tests and file hashes accompany the source.

This release covers reusable method implementations and portable companion components. Cohort-specific data, reference bundles and some historical execution wrappers are supplied through the documented data-access route. The historical June 2026 plotting scripts remain separately labelled. Availability of this snapshot does not mean all later manuscript figures can be regenerated from a package installation alone.

No project software reuse licence has yet been selected; do not describe this source as permissively licensed.
